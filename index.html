A 2D seismic line, from SEG-Y to classes

Open a 2D line, check and condition it, compute seismic attributes, classify them with a self-organizing map, and use SHAP values to see which attributes the classes rest on. Everything is computed in this browser from the file itself.

Post-stack, one line. Drag the file here or choose it.

Sample line: SCAN029, the Netherlands

Pre-stack time migrated full stack from the SCAN geothermal exploration programme, run by EBN and TNO. The line runs about 48 km across the southern Netherlands, from the Someren area in the west to the Californië geothermal wells near Venlo in the east. 2425 traces at 20 m, 2 ms sampling, 0.15 to 3.0 s.

Data from NLOG. The copy here is an interim one, rebuilt from an 8-bit display array; data/README.md describes it and how it is replaced.

Each step writes its result to storage in this browser, and the next step starts from it. Steps 3 to 6 can be skipped: a skipped step passes the line through unchanged. Opening a new line clears everything computed from the previous one.
